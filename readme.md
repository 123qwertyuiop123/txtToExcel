# TXT 转 Excel

把按天记录的消费文本转换为年度 Excel 工作簿。工作簿包含 `1月` 至 `12月` 和 `总计` 工作表。

生成的年度工作簿还包含“分类统计”工作表：支出原因和收入来源分开汇总，金额从高到低排列，以公式计算占比，并分别生成饼图。原有月份页和“总计”页的样式保持不变。

支出分类采用保守规则，只合并含义明确的项目：

- `早饭、早餐、午饭、晚饭、夜宵、KFC、烧烤、饮料、奶茶、咖啡、外卖` 等合并为“餐饮”。
- `火车票、高铁票、机票、打车、公交、地铁、交通` 等合并为“交通”。
- `原神、崩坏` 等合并为“游戏消费”。
- `挂号、药品、医院、看病` 等合并为“医疗”。
- `宽带、话费、流量、网费` 等合并为“网络通信”。
- `购物、生鲜、网吧、裁缝` 等含义不够明确的项目保留原名称；收入来源也保持原名称。

## 代码结构

- `main.py`：程序启动入口和命令行参数。
- `gui.py`：主窗口、游戏消费窗口和年度合并窗口。
- `expense_converter.py`：普通月度消费 TXT 的检查、解析与 Excel 生成。
- `game_converter.py`：年度游戏消费 TXT 的检查、解析与 Excel 生成。
- `year_merge.py`：多个年度消费统计 Excel 的检查与合并。
- `models.py`：普通消费和游戏消费的数据模型。
- `money_utils.py`：金额舍入、显示和 Excel 数值转换工具。
- `excel_utils.py`：Excel公式注入防护和临时文件安全保存。
- `category_rules.py`：明确消费原因的保守合并规则。

## 文本格式

文件建议命名为 `2025年1月消费.txt`：

```text
1日:原神:976
2日:早饭:8,午饭:14.5
3日:收入:+600,购物:98.6
```

- 金额以 `+` 开头：收入，不计入支出。
- 收入项目不显示在当天消费明细中，统一汇总到月份工作表最下面。
- 无符号金额：支出。
- 负数金额：仍按支出处理，并取绝对值。例如 `消费:-20` 计为支出 520。
- 中文或英文逗号、冒号都可以使用。
- 推荐使用 `项目:金额`；如果偶尔漏写冒号或逗号（例如 `晚饭10父母:+600`），程序也会尝试自动恢复。
- 也兼容常见误写，例如 `晚饭:13,1` 按 `13.1` 处理，`午饭,14.7` 按 `午饭:14.7` 处理。
- 无法恢复的内容会明确报错，不会再静默跳过并生成错误合计。
- Excel 金额最多显示一位小数；整数不显示小数点。

## 图形窗口（推荐）

先安装依赖：

```powershell
pip install -r requirements.txt
```

然后直接双击 `main.py`，或者运行：

```powershell
python main.py
```

在窗口中可以一次选择一个或多个月份的 TXT 文件。选择后必须先点击“检查文件”；程序会严格检查文件名年月、年份一致性、重复月份、日期和每条明细格式。全部通过后才会启用“开始转换”。检查失败时会列出文件名、行号、日期、问题内容和修改建议。

检查通过后，程序会根据类似 `2025年1月消费.txt`、`2025年2月消费.txt` 的文件名，把数据分别写入同一个 Excel 的 `1月`、`2月` 工作表。多选文件必须属于同一年。如果检查后修改了 TXT 或年月，需要重新检查。

## 打包为 Windows EXE

直接双击项目中的：

```text
一键打包.bat
```

脚本不会联网，也不会安装或更新任何组件，只使用项目 `.venv` 中已有的打包环境。也可以在项目目录打开 PowerShell，运行：

```powershell
.\build_exe.ps1
```

生成文件：

```text
dist\消费统计转换工具.exe
```

生成的是免安装单文件GUI程序，复制 `dist\消费统计转换工具.exe` 到其他Windows电脑后即可双击运行，目标电脑不需要安装Python或项目依赖。

## 已知风险与限制

- 生成的EXE没有商业数字证书签名，其他电脑首次运行时可能出现Windows SmartScreen提醒。
- 转换和合并会在用户确认后覆盖同名输出文件；程序会先完整写入同目录临时文件，再原子替换目标，保存失败时保留旧文件。
- TXT和Excel解析在GUI主线程运行，异常大的文件可能使窗口在处理期间暂时无响应。
- 来自TXT且以 `=、+、-、@` 开头的项目名和游戏名会被强制保存为纯文本，不会作为Excel公式执行。
- “检查后是否修改”通过文件路径、修改时间和大小判断，用于防止日常误操作，不等同于防恶意篡改的数字签名。
- “一键打包”本身依赖项目现有 `.venv`；免安装的是最终生成的EXE，不是开发环境。

## 合并多个年度 Excel

主窗口底部点击“合并年度 Excel…”，可以多选 `2023年消费统计.xlsx`、`2024年消费统计.xlsx`、`2025年消费统计.xlsx` 等文件，生成一个 `年份统计.xlsx`。

- 新文件包含“年份统计”总表，汇总每年的支出、收入和结余。
- 新工作簿只保留“年份统计”和每个年份的总情况工作表，例如 `2024年`、`2025年`。
- 不复制各月份明细工作表；年度总情况中的月份数据会转换为实际数值，避免出现无效公式引用。
- 输入文件必须是不同年份，并包含完整的 `1月` 至 `12月` 和 `总计` 工作表。

## 年度游戏消费 TXT

主窗口底部点击“游戏消费 TXT…”，可以多选 `2024年游戏.txt`、`2025年游戏.txt`、`2026年游戏.txt`，生成同一个 `游戏消费统计.xlsx`。

支持以下三种行格式：

```text
1月29日:原神:68
2025年1月29日:原神:68
2025年:1月29日:原神:68
```

- 文件名必须使用 `某某年游戏.txt`，每个年份只能选择一个文件。
- 选择后必须先点击“检查文件”；失败时会列出具体文件、行号和问题。
- 输出工作簿包含“游戏统计”总表，以及 `2024年`、`2025年` 等年度工作表。
- 每个年度工作表包含逐笔日期、游戏、金额，同时提供月度汇总和按游戏汇总。
- 金额最多显示一位小数；整数不显示小数点。

## 命令行使用方法

```powershell
python main.py "2025年1月消费.txt"
```

一次转换多个文件：

```powershell
python main.py "2025年1月消费.txt" "2025年2月消费.txt" -o "2025年消费统计.xlsx"
```

转换一个目录中的多个月份文件：

```powershell
python main.py ".\2025消费记录" -o "2025年消费统计.xlsx"
```

当文件名没有年月时，可手动指定：

```powershell
python main.py "消费.txt" --year 2025 --month 1
```
